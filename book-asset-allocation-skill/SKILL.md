# Book Asset Allocation Skill v0.1

## Purpose

根据投资书籍方法论，对用户个人现金流、资产结构和新增资金进行资产配置分析。

## Workflow

1. 收集用户输入：
   - 月收入
   - 月支出
   - 现金余额
   - 各类投资资产余额
   - 未来 1-3 年大额资金需求
   - 风险偏好

2. 计算：
   - 总资产
   - 可投资资产
   - 当前资产比例
   - 与目标配置比例的偏离

3. 根据目标配置提出调整方案：
   - 优先使用新增资金再平衡
   - 避免频繁交易
   - 保留应急现金

## 默认参考配置

公开资料整理版本：

- 固收类：50%
- A股指数增强：35%
- 黄金：10%
- QDII：5%

该比例不是收益保证，仅作为一种资产配置框架。

## Output Format

输出：

1. 当前资产诊断
2. 当前比例与目标比例差异
3. 本月新增资金分配建议
4. 调整后预计比例
5. 风险提醒

## Safety Rules

- 不承诺收益
- 不保证本金安全
- 不替代专业投资顾问
- 重大资产决策需结合用户实际情况
