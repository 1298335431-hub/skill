# 《睡后收入的真相》方法论摘要（公开信息版）

## 当前核实状态

本 Skill 对应书籍为：珈一《睡后收入的真相：怎样让你躺着就能赚钱》。微信读书公开搜索结果显示，该书强调“不做投机，做投资”，并设置了关于二级债基、A股指数增强、黄金、QDII 和再平衡的专门章节。

由于当前无法直接读取微信读书的完整受版权保护正文，本文件仅整理公开页面可见目录信息与公开读者总结，属于“方法论提炼”，不是原文复制，也不能视为完整书摘。

## 可核实的核心框架

### 1. 从投机切换到长期经营

核心不是靠短线择时或频繁盯盘获得收益，而是把个人财富当作一个长期经营的系统。目标是降低决策频率、降低情绪消耗、依赖资产本身长期运作。

### 2. 四类资产的分工

当前最完整且能自洽到 100% 的公开读者总结给出：

| 类别 | 目标比例 | 角色 |
|---|---:|---|
| 二级债基 / 固收+ | 50% | 组合底盘、降低整体波动 |
| A股指数增强 | 35% | 核心增长引擎 |
| 黄金 | 10% | 尾部风险、货币与危机对冲 |
| QDII | 5% | 海外分散，降低“家乡偏误” |

注意：该精确比例来自公开读者笔记，而不是当前直接读取的完整书页。因此若用户提供书中原文，应以原文为准校准。

### 3. 再平衡

微信读书公开目录明确出现“再平衡”章节，其意图是让系统通过恢复目标比例实现纪律化的“卖高买低”。公开读者笔记总结为每半年到一年检查一次。

实操上优先使用新增资金补低配项，可以减少不必要卖出、交易成本和税务影响。只有在正式再平衡或用户明确同意时，再讨论卖出高配项。

### 4. 低频操作

该体系的价值不只是资产比例，而是让投资从“高频操作”转向“规则化、低维护”的流程。Skill 应鼓励用户建立固定记账与半年/年度检查，而不是因为短期涨跌改变目标配置。

## Skill 的额外安全层

以下不是本书公开内容的直接摘录，而是为了避免机械套用组合：

1. 应急金与未来 1–3 年刚性支出不进入长期投资组合。
2. 高利率债务需要优先单独评估。
3. 不借钱投资、不使用杠杆。
4. 不把目标配置理解成收益保证。
5. 若要推荐具体基金/ETF，必须基于当前信息再次研究，不能把产品名单永久写死。
