# 联网研究清单

## 候选发现查询

围绕产品类别生成多组搜索词：

- `{产品类型} 软件 / 平台 / App / SaaS`
- `{目标用户} {核心任务} 工具`
- `best {product category} for {user}`
- `{竞品名} alternatives / competitors`
- `{核心任务} workflow / solution`
- `{产品类型} pricing / 定价 / 收费`
- `{产品类型} demo / tutorial / 教程 / 帮助中心`
- `{产品类型} reviews / 评价 / 投诉`
- `{产品类型} API / integration / 私有化部署`
- `{产品类型} 行业解决方案 / 客户案例`

再搜索替代方案，例如 Excel 模板、人工服务、外包、通用协作工具或线下流程。

## 单个竞品查询

对入选竞品分别检索：

- 官网和公司主体。
- 产品、功能、解决方案、客户案例。
- 定价、免费试用、退款、合同周期。
- 帮助中心、文档、学院、视频、网络研讨会。
- 联系我们、支持、销售咨询、客服电话、客服邮箱。
- 应用商店页面和版本更新记录。
- 第三方评测、社区反馈、故障或停服信息。

## 证据记录

对关键页面记录：

- 页面标题。
- 页面 URL。
- 发布或更新日期，没有则写未知。
- 本次访问日期。
- 支持的具体结论。
- 来源类型和可信度。

同一页面不要被伪装成多个独立来源。转述原始报告的新闻文章不能代替原始报告。

## 停止条件

满足以下条件即可进入报告阶段：

- 重点竞品已经覆盖头部、代表性新产品和一种替代方案。
- 每个重点竞品至少有一个官方来源。
- 影响决策的关键数据已经交叉验证，或已明确标记无法交叉验证。
- 新增搜索结果大多重复现有信息。
