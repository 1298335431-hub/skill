# 首轮需求提问模板

只在用户给出的信息不足以确定竞品范围时使用。将已经明确的问题删掉，并为剩余问题给出推测的默认值。

推荐表达：

“我先按你的产品类型把范围圈准。下面这些不需要写得很完整，不确定的可以写‘不确定’，也可以直接回复‘按默认值继续’。”

1. 你准备做 Web、App、小程序、桌面软件、API、硬件，还是组合产品？
2. 最主要的使用者是谁？最终掏钱的人又是谁？
3. 它最核心要帮用户完成哪件事？如果只能保留三项功能，会是哪三项？
4. 先做中国大陆市场，还是某个海外市场？
5. 你倾向订阅、按量、佣金、一次买断，还是还没确定？
6. 现在处于想法、原型、已上线，还是已经有客户？
7. 有哪些必须有、绝对不要或受预算与合规限制的条件？
8. 如果有官网、原型、产品说明或你已经知道的竞品，可以一起给我。

提问后列出“我暂时采用的默认值”，最多五条。用户回答后，不重复询问已回答内容。

## 研究口径确认模板

用一小段话复述：

- 产品类别和核心任务。
- 目标用户与付费者。
- 产品形态和地区。
- 重点比较维度。
- 直接竞品、间接竞品和替代方案是否都纳入。

除非用户纠正，否则随后直接开始研究。
